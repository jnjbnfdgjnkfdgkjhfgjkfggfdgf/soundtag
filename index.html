NFC · multi-device audio · no apps

Tap one tag.
Every phone plays sound.

SoundTag turns a single NFC tag into a room full of speakers. Every phone that taps it joins the same stream — one panel, one tap, everyone hears it.

Get started Star on GitHub

Sound, everywhere at once

No installs on guests' phones, no accounts, no store review. Just a browser and a tap.

01 — TAP

No apps to install

Standard NFC opens a web page. Guests download nothing and sign up for nothing to join.

02 — SYNC

Every phone together

All connected devices pull one shared stream and play the same audio at the same moment.

03 — CONTROL

Run it from one panel

Upload a file, tap its name to broadcast. A local sign-in keeps the panel yours alone.

Up and running in minutes

You'll need Node.js and ffmpeg. The installer creates a soundtag folder, installs everything, and starts on port 3000.

Then
1
Run the installer

Paste into a terminal — it downloads SoundTag, installs deps and launches it.

curl -fsSL https://raw.githubusercontent.com/soundtag1/soundtag/main/install/install.sh | bash
2
Set your own login

Pick credentials before starting. Skip it and a random password prints on first run.

export SOUNDTAG_USER=admin export SOUNDTAG_PASS=your-secret-password
1
PowerShell, one line at a time
irm https://raw.githubusercontent.com/soundtag1/soundtag/main/install/install.ps1 -OutFile install.ps1 powershell -ExecutionPolicy Bypass -File .\install.ps1
2
Or double-click install/install.bat

Prefer a click? Grab the batch file from the repo and run it.

3
Set your own login
setx SOUNDTAG_USER admin setx SOUNDTAG_PASS your-secret-password
1
Expose port 3000

Share your machine's IP on the network, or port-forward / tunnel (e.g. playit.gg) for the open internet.

2
Point the tag at the listener

Program the NFC tag (or a QR code) to open the blank listener page. One tap there unlocks audio.

https://your-public-url/listener
3
Open the panel and sign in

Upload .mp3 / .wav / .ogg / .m4a, then tap a name to send it to every phone.

https://your-public-url/control

What it can't do (on purpose)

It can't raise system volume, override silent/mute mode, or play before a tap — those are iOS/Android rules, not missing features.

Close the listener page and that phone stops. It isn't a background app.
