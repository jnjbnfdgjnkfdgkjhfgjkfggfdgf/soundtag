01

What it actually does

Each phone taps the tag — or scans a QR code — and opens a plain listener page. One tap on that page satisfies the browser's audio rules and locks the phone onto a central stream. From a password-protected control panel you upload sounds, tap a name to broadcast it to every connected phone, or go silent without dropping anyone. Nothing to install on guests' phones, no accounts, no store review — just a browser and standard NFC.

02

Why people use it

A

No mobile apps

Standard NFC opens a web page. Guests install nothing and hand over nothing.

B

Every phone, in sync

All connected devices pull the same stream and hear the same audio at once.

C

One small control panel

Upload a file, tap its name to play. A local sign-in keeps the panel yours.

D

Stop means silence

Cut the audio to quiet without disconnecting a single listener from the stream.

E

Runs anywhere

iPhone (iOS 13+), Android, Windows, macOS, Linux — anything with a modern browser.

F

Yours to change

MIT-licensed and small enough to read in one sitting. Fork it, host it, bend it.

03

Get it running

You'll need Node.js and ffmpeg. The installer drops a soundtag folder next to you, pulls dependencies, and starts the server on port 3000.

Run the installer

Paste into a terminal. It downloads SoundTag, installs deps, and launches it.

Set credentials before starting. Skip this and a random password prints to the console on first run.

What it can't do (on purpose)

— It can't raise system volume, override silent/mute mode, or play before a tap. Those are iOS/Android rules, not missing features.

— Close the listener page and that phone stops. It isn't a background app.
