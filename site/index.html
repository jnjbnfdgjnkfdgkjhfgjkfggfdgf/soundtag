What is SoundTag?

One tag, every phone, in sync

Each phone taps the tag (or scans a QR code), opens a blank listener page, and — after a single tap to satisfy the browser's audio rules — locks onto a central stream. From a simple web control panel you upload sounds, tap a name to broadcast it to every connected device, or silence the stream without dropping anyone. No app installs, no accounts on the phones, just a browser and standard NFC.

📲

No mobile apps

Uses browsers and standard NFC to open the listener page. Nothing to install on guests' phones.

🔊

Many devices at once

Every connected phone hears the same audio at the same time from one shared stream.

🎛️

Simple control panel

Upload audio files and tap their names to play. Password-protected sign-in keeps it yours.

🤫

Stop = silence

Stop playback to go silent without disconnecting a single listener.

💻

Cross-platform

iPhone (iOS 13+), Android, Windows, macOS and Linux — anything with a modern browser.

MIT licensed

Install guide

Up and running in a couple of minutes

You'll need Node.js and ffmpeg installed. Pick your platform below — the installer creates a soundtag folder, installs dependencies and starts the server on port 3000.

macOS / Linux
Windows
After it starts
1
Run the one-line installer

Paste this into your terminal. It downloads SoundTag, installs dependencies and launches the server.

curl -fsSL https://raw.githubusercontent.com/soundtag1/soundtag/main/install/install.sh | bash
2
Set a control-panel password (recommended)

Before starting, choose your own sign-in credentials. If you skip this, a random password is generated and printed to the console on first run.

export SOUNDTAG_USER=admin export SOUNDTAG_PASS=your-secret-password
1
Download the installer

Run these in PowerShell one at a time.

irm https://raw.githubusercontent.com/soundtag1/soundtag/main/install/install.ps1 -OutFile install.ps1 powershell -ExecutionPolicy Bypass -File .\install.ps1
2
Or use the batch file

Prefer double-clicking? Download and run install/install.bat from the repo.

3
Set a password (recommended)

Choose your own sign-in credentials before launching.

setx SOUNDTAG_USER admin setx SOUNDTAG_PASS your-secret-password
1
Expose port 3000

For phones on your network, share your machine's IP. For internet access, port-forward 3000 or use a tunnel such as playit.gg.

2
Program your NFC tag (or QR code)

Point it at the blank listener page. One tap on this page unlocks audio on that phone.

https://your-public-url/listener
3
Open the control panel & sign in

Go to the control panel, sign in with your credentials, upload .mp3 / .wav / .ogg / .m4a files, and tap a name to broadcast it to every connected phone.

https://your-public-url/control

Honest limits

  • It cannot change system volume, bypass silent/mute mode, or play without a user tap — those are iOS/Android restrictions, not bugs.
  • It does not keep playing once the listener page is closed.
